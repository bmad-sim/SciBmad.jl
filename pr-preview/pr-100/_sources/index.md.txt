# SciBmad.jl User Guide

SciBmad is a high-performance, CPU/GPU-compatible, fully-differentiable accelerator physics
simulation ecosystem, usable from both Julia and Python.

This documentation is a work in progress. Please also see the
[examples](https://github.com/bmad-sim/SciBmad.jl/tree/main/examples) and
[slides](https://github.com/user-attachments/files/25094046/scibmad-eic-02-02-2026.pdf)
until this is complete.
