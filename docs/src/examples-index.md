# Examples

These are complete Jupyter notebooks that you can run yourself. The pages show them with the
outputs, including figures, from when they were last run. The notebooks are in the
[`examples/`](https://github.com/bmad-sim/SciBmad.jl/tree/main/examples) directory, in Julia
(`examples/julia`) and in Python (`examples/python`); these pages show those of the language
chosen at the top of the page.
